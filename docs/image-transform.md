# 图片变换工具

选中一张浮动图片后，点击「变换工具」或按 **T**。未选中图片时，该工具禁用。

- 图片显示四角及四边中点共 **8 个控制点**。
- 拖动角点调整宽高，拖动边中点单独调整宽度或高度。
- 鼠标移至角点外侧，光标变为弧形旋转箭头，按住左键拖动即可绕图片中心自由旋转。角点控制块本身仍用于缩放。
- 旋转时按住 **Shift**，角度按 **15°** 对齐。
- 按住 **Shift** 拖动控制点保持宽高比。
- 按住 **Alt** 以图片中心为基准对称缩放。
- 按住 **Shift + Alt** 同时保持宽高比和中心位置；透视图片的中心指展开曲面中的中心。
- 拖动图片内部移动图片；点击另一张图片切换选中。
- 点击图片以外的空白区域取消选中，退出变换工具。
- 松开鼠标提交本次变换，可撤销、重做；拖动期间按 **Esc** 恢复到本次拖动前。

缩放和旋转只修改图片的变换参数，原始位图保持不变，避免反复重采样。顶部不再显示旋转及镜像翻转按钮。

已吸附图片在其几何快照的展开曲面坐标中移动、缩放和旋转。控制点分别投影到所在的面，图片横跨多个面时，内容和蚂蚁线也按各面的透视规则分段更新。变换不会修改透视平面的几何。
