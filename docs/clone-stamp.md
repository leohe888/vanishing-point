# 图章工具

打开图像并创建透视平面后，按 **S** 切换图章工具。

- **Alt + 鼠标左键**：设置源点，绿色十字准星标记当前取样位置。
- **左键拖动**：从透视平面内开始仿制，整笔沿该平面的透视延伸。
- **直径、硬度、不透明度**：在侧栏调整，与画笔工具共享参数。
- **对齐**（默认勾选）：保持源点与目标点在展开坐标中的偏移，松开鼠标后准星仍随光标移动，下一笔继续取样。
- **取消对齐**：绘制期间准星跟随，松开鼠标后回到最初源点，每一笔重新从该源点取样。

源点位于平面内时，按源平面透视取样；位于平面外时，按图像像素取样。复制内容与圆形笔刷在展开坐标中计算，再投影到目标平面。每笔从落笔前的画面快照取样（包含背景、已有绘画和浮动图像，不含网格与准星），结果写入现有绘画层，支持撤销、重做、清除和导出。

可用 CMake 选项 `-DVP_BUILD_TESTS=ON` 构建 Qt Test 回归测试，再运行 `ctest --test-dir <构建目录> --output-on-failure`。测试覆盖透视采样、硬度、不透明度、取样快照、源图边界、两种对齐模式、快捷键、撤销重做与导出。
